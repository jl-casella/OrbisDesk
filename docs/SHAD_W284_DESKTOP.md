## General fork corrections

- ET_SCE_EXEC use the linked addresses, with zero relocation bias. The reservation, the trampoline, the direction searches and the image size are calculated on the actual extension of the segments, not including the gap before the first PT_LOAD. ET_SCE_DYNEXEC retains its previous route.
- sigsetjmp/siglongjmp and the variants setjmp/longjmp guardan/restauran records, FPU control and masks according to ABI FreeBSD. The inputs are linked without a wrapper C that introduces an additional frame in the saved context.
- Each guest thread has an alternative host stack for signals.
- getppid offers a syscall libkernel entry point. PID, PPID, sigaction, write and exit are sent to the emulator services. The unknown calls return ENOSYS, with the corresponding cartage indicator.
- The contexts translate CS selectors Linux 0x33/0x23 to PS4 0x43/0x33 and vice versa. The CS 0x43 is also observed in the physical Runs W284 archived.

The jumping functions use the layout of [FreeBSD amd64 sigsetjmp](https://github.com/freebsd/freebsd-src/blob/releng/9.3/lib/libc/amd64/gen/sigsetjmp.S) as a reference and keep their attribution / license in the new file.
